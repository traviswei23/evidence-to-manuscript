# 从证据排出论文的论证顺序

## 先定读者会质疑什么

给熟悉大领域但不了解本项目的读者写一句研究问题、一个当前答案、最强证据和可能推翻它的解释。分别试两种开头，例如从已知瓶颈出发，或从意外现象出发。比较哪条路径更少依赖尚未交代的概念，哪条更早展示决定性证据。如果主线改变会把论文从“发现现象”改为“解释机制”，把两条主线及各自的证据代价交作者选择。

已提供开题方案时，将其“计划验证”逐项回填为已完成、未完成、结果不同；已有查新报告时只继承核实过的具体差异。计划主张与结果冲突，以实际观察组织稿件。

## 选能承载这批证据的结构

| 材料形态 | 推荐排序 | 检查点 |
|---|---|---|
| 实验或测量 | 问题 → 实验设计、表征或校准 → 主要结果 → 对照及解释 → 局限 | 读者能否从对照判断观察成立的条件？ |
| 理论与推导 | 问题 → 共享前提 → 命题 → 决定性论证 → 例子或适用边界 | 命题所需的假设是否在第一次使用前给出？ |
| 工程系统与方法 | 约束 → 设计选择 → 操作或数据流 → 公平比较 → 失效场景 | 能否把每个设计选择连回一个问题和一项评估？ |
| 综述、观点或论证性文章 | 范围与争点 → 不同解释及其证据 → 综合判断 → 未决问题 | 是否把作者的综合判断与所引论文的发现分开？ |

一项工作兼有推导和实验时，选主张所需的顺序，把另一条作为支持。不要为填满模板拆成互不相干的两篇论文。引言可用“背景、具体困难、解决思路、本文证实了什么”的顺序。短文可合并这些动作；不为凑段数填背景。

## 按整组图重建论证

1. 从稿件或摘要加图注写简报，包含拟回答的问题、读者、最强发现，每图用一句能对照图像的话概括。打开整组实际图片，核对每个面板的真实内容。
2. 给每张图记录“读者进图前知道什么 → 面板展示什么 → 看完能得出什么 → 下一张仍须回答什么”。有多个面板时，分清方法示意、对照、主要读数、稳健性证据。若面板支持另一问，先试调序或跨图移动。
3. 针对第一张主图问“仅凭该图，编辑能看见什么值得继续阅读的现象或关键能力？最有说服力的画面是否被埋在后面？”原理说明不可读时才优先展示装置或方法图。封面感、美观或有利结果不能替代证据。
4. 依次标记保留、合并、移到补充、从本次稿件删去。对缺失面板写明需要的分析、是否已有原始记录，以及它会改变哪条判断。已有图用于重排可操作；缺实验时将其作为待补工作并收紧结论。
5. 数值不齐、样本太少或机制图无法核实时，降低展示复杂度。精确比较用表，趋势可画图，信息少则用一句文字。重复呈现同一数据只在该视图揭示另一项必要比较时保留。图注需有面板定义、单位、样本层级和误差解释，版中首引要说明读者应看哪里。
6. 重读新图序。若整套图回答不了主问题，回到证据记录修改主线。一次修订解决不了的分歧，交付可写的路径及缺失条件。

## 从图序到段落

以一到两页的分层提纲组织长稿，每节的标题下写“本节回答的问题、读者要相信的一句话、证据位置、下一节的问题”。将标题串在一起，再只读各段首尾句，两次都应能循序理解论证。研究对象或符号在被定义之前使用，通常说明顺序错了。

每个小节先列论点句及其依据，再展开“这句话声称什么、读者凭什么相信、为什么证据足够”。给各节设与期刊或用户字数限制相容的预算。理解结论不可缺的主证据放正文；供复算、复现、查证边界所需的推导和参数放附录，并从正文明确指向。分配到正文和附录以后，再回头删去只在附录中使用的正文记号。

# 二十个原来源怎样进入一次实际写作

在执行[整稿循环](manuscript-loop.md)时按下表核对材料。第二列是执行者应完成的动作，第三列给出它在成稿或底稿中留下的痕迹。链接定位到相应上游入口和配套文件。单节和改稿任务保留原定范围。

| 来源 | 哪一步实际使用 | 怎么核准 |
| --- | --- | --- |
| [S01 paper-writer](source-map.md#s01) | 写段落前，将作者观察、原始记录与外部文献分栏。碰到新的事实句先查依据。 | 给任一核心句能找出一种确定的依据和位置。 |
| [S02 paper-narrative](source-map.md#s02) | 先只看图和图注重建读者会理解的故事，再与作者原意比较；尝试调换面板或删除重复图。 | 看重排后的整组图能解释主张，并说明第一幅图最多能支撑什么。 |
| [S03 research-results-writer](source-map.md#s03) | 选问题、条件或组件为结果段的主轴，给图和比较基准，写明方向和幅度。 | 每个结果段有一个结果；涉及数据的中心句能追到同口径的对照。 |
| [S04 research-discussion-writer](source-map.md#s04) | 给关键结果写两种可能解释，用已有对照或前作指出可区分的条件。 | 讨论中的因果动词与实际设计相符，无法区分之处留下边界。 |
| [S05 manuscript-drafter](source-map.md#s05) | 从作者旧稿提取术语和语气，为每节确定读者问题和字数预算，再展开成段。 | 沿用作者主张、引文习惯和限定词；另列需要作者决定的取舍。 |
| [S06 scientific-writing](source-map.md#s06) | 对照研究设计选须报告的条件、样本、误差、数据来源和声明；从方法对账结果。 | 声明有授权或材料依据；统计量由特定分析产生。 |
| [S07 nature-writing](source-map.md#s07) | 按实际读者和期刊选背景深度，摘要用主发现与适用边界收束。 | 从摘要数字和限定语能回到正文；结果没有被升格为普适规律。 |
| [S08 paper-spine](source-map.md#s08) | 接续作者已有材料、图、主稿和版本，修订时改最先产生错误的位置再渲染。 | 交付可编辑文件；需排版时实际打开最终件并记录受影响的页。 |
| [S09 scholaraio paper-writing](source-map.md#s09) | 从已有论文笔记和引文键回到原文，为引言、相关工作及方法分别选择来源。 | 引用为该节内的具体判断服务，正文和书目能双向核对。 |
| [S10 msimchowitz paper-writing](source-map.md#s10) | 用一项可辨的技术区别组织每节，核查观察、提示、证明的动词力度。 | 近似工作之间可用读者能查验的技术条件区分。 |
| [S11 SNL-UCSB paper-writing](source-map.md#s11) | 从组会材料找出真正改变设计的决定，分开做论证审查和机械检查。 | 被删或挪段落的必要定义和引用能在新位置找到。 |
| [S12 physics-paper-outline](source-map.md#s12) | 将相信论点所需的假设、极限、主推导写进正文，较长复算步骤放附录。 | 第一次出现的符号可辨；正文自身仍足以理解推理。 |
| [S13 paper-outline-generator](source-map.md#s13) | 根据推导、实验、参数扫描或系统评估选择结构；每个子问题指定支持数据。 | 核心图不存在时切换证据形式或收窄段落，不生成虚构图号。 |
| [S14 write-methods](source-map.md#s14) | 从约束到输入、变换、输出、下一步用途，逐一解释关键方法与朴素基线。 | 读者能按顺序还原流程、边界与关键设置。 |
| [S15 results-section-revision](source-map.md#s15) | 用上段尚未回答的问题开启下一结果段，修断裂的面板过渡。 | 逆读段首能复原论证次序，删去图号后仍有实质信息。 |
| [S16 paper-argument-reconstructor](source-map.md#s16) | 需要重写时先标原主张、障碍、机制、实验，复核是否真的回应了问题。 | 重写后数字、符号和原推断范围逐项相同，改错有原始记录支撑。 |
| [S17 paper-claim-audit](source-map.md#s17) | 从实际稿件提取关键断言，对原表复算；交给新上下文审阅时冻结实际材料。 | 错数和证据变更能被发现，自审或独立审查按实际身份报告。 |
| [S18 evidence-grounded-paper-writing](source-map.md#s18) | 将作者已证实结果与他人文献分开，按稿件任务选写作、文献或公式核实支路。 | 找不到原始出处的背景、公式或结果不进入清稿。 |
| [S19 claimscope](source-map.md#s19) | 区分描述、相关、因果、泛化与应用，分别问每项证据支持到哪一级。 | 摘要、图注及讨论里出现的强措辞在原设计中有相应判别证据。 |
| [S20 abstract-writing](source-map.md#s20) | 正文稳定后把问题、方法、最重要的实际结果和边界写成同一条论证。 | 从摘要倒查正文；两边对象、分母、语义与适用范围一致。 |
